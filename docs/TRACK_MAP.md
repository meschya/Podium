# Карта трассы и лайв-гонка

## Как это устроено в индустрии

- **Официальный тайминг F1** передаёт позиции машин на трассе в реальном времени; приложения (F1 Race Guide, Formula Live Pulse, F1Dash, MultiViewer) показывают их на карте трассы.
- **OpenF1** даёт те же типы данных без ключа: эндпоинт **Location** (`/v1/location?session_key=latest`) — координаты (x, y) каждой машины ~3.7 раз в секунду во время сессии.
- **Координаты** (x, y) — в единой «трековой» системе (дециметры от условного нуля). Чтобы нарисовать точку на карте, их нужно привести к координатам карты трассы.
- **MultiViewer** (и FastF1) предоставляют **circuit_info**: центральная линия трассы в тех же координатах (x, y) + **rotation** (градусы) для выравнивания с официальной картой. Данные ручные, «не идеально точные, но достаточные для визуализации».

## Что есть в Podium

1. **Трасса**
   - Если у этапа есть `circuit_info_url` (OpenF1 → meeting) — грузим circuit_info с MultiViewer (массивы `x`, `y` центральной линии + `rotation`).
   - Трассу **рисуем сами** по этой центральной линии (с учётом rotation), чтобы кружки машин и контур трассы были в одной системе координат.
   - Если circuit_info нет — показываем фото трассы из API (circuit_image) и кружки по овалу (без привязки к контуру).

2. **Симуляция**
   - Машины едут по прогрессу 0…1 вдоль центральной линии из circuit_info; позиция на экране: `pointAtProgress(progress)` → (u, v) → пиксели. Кружки всегда на нарисованной трассе.

3. **Лайв-гонка** (как отображать)
   - Берём **текущую сессию**: `session_key=latest` (или session_key гонки).
   - Периодически (например раз в 0.3–0.5 с) запрашиваем **Location**:  
     `GET /v1/location?session_key=latest`  
     Получаем список записей `{ driver_number, x, y, date, ... }`.
   - Для каждого драйвера берём **последнюю** запись по `date` (последняя известная позиция).
   - По координатам (x, y) получаем точку на нашей карте:  
     `circuitInfo.normalizedUV(trackX: loc.x, trackY: loc.y)` → (u, v) в [0, 1].
   - Рисуем кружки на том же view, что и трассу: позиция = (u * width, v * height). Машины двигаются по той же нарисованной трассе.
   - Дополнительно можно подписать кружки номером/именем и показывать интервалы из эндпоинта **Intervals**.

## Ограничения

- **Точность**: circuit_info и координаты — ручные/приближённые; возможны небольшие смещения контура трассы.
- **Лайв только при активной сессии**: данные Location есть, когда сессия идёт (практика, квалификация, гонка); для исторических гонок можно брать сохранённые срезы или не показывать карту.
- **OpenF1**: лайв по подписке; исторические данные (с 2023) бесплатны.
